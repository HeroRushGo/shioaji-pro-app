## Authority and startup

Use a dedicated market-only launcher, not the upstream `.env` dev-api route. The canonical neo-client `load_shioaji_credentials()` verifies the receipted credential bytes before mapping the two Shioaji keys into a child-only environment. The workstation credential policy requires Trading=false and no CA. Never read or log keys, account records, environment dumps, or credential files through tools.

The official pinned Shioaji 1.7.11 arm64 binary is digest-verified before installation in ignored `src-tauri/binaries/`. Launch from the existing `ops/workstation-vendor-run.zsh` log-custody root with a NEW private `SJ_HOME_PATH` per invocation, umask 077, explicit `SJ_LOG_PATH`, UDS disabled, and no inherited CA/auth/harness secrets. Raw CLI is production market data, loopback 21324, `--auth`; Bearer key material stays in launcher/gateway memory. No browser receives it. Never attach, probe, stop or fall back to 21322/8080. Fail if owned ports are occupied; stop only groups of this launch, checking group survival independently of leader exit before bounded KILL escalation. Remove only this invocation’s generated SDK directory after group cleanup.

A separate Node gateway binds 127.0.0.1:21323. It forwards only explicit market method/path combinations; unknown, encoded/ambiguous paths, broker/account/portfolio/auth/admin/app routes and cross-site requests fail before forwarding. It inserts raw CLI authentication internally. Health/info are projected onto an explicit non-PII field set. Aggregate SSE is parsed with bounded frame buffering and forwards only named market/contract/heartbeat families, discarding order and unknown events. Requests/responses have limits, timeout/abort handling, no redirects, no forwarded cookies/auth headers, no sensitive logs. Browser Vite is loopback 5173 with exact same-origin proxy and CSP connect-src self (plus its local HMR). Raw CLI public health/info metadata remains an upstream residual surface; protected account/order routes require authentication and provider key denies trading.

Watchlist CRUD is explicitly local display configuration: the gateway handles `/api/v1/watchlist` and its typed contract-member routes using only a private JSON file under pro-web-state. These requests never open an SDK connection. This is separate from the prohibited upstream/account/broker mutations. It persists when each fresh SDK session is removed.

The opt-in `market` frontend mode pins same-origin API/SSE, skips order/strategy/conditional execution runtimes, account/trade subscriptions and normal trading bootstrap, verifies backend version/health then opens quotes. The visible app marks 行情唯讀. Central API client fails closed on disallowed operations. Normal default upstream mode is unchanged. A forbidden trading panel may remain in the full workspace but it must never unlock dispatch in this profile.
